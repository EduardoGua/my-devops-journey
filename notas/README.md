# Mis notas

Aquí van **tus** cierres: un archivo por clase, con tus palabras. No copies la lección.

```
notas/fase-1/clase-01.md
notas/fase-1/clase-02.md
...
```

## Plantilla

```markdown
# Clase 01 — La terminal, el shell y el kernel
Fecha: 2026-10-05
Tiempo: 70 min

## Cierre
1. ...
2. ...
3. ...
4. (repaso, sin mirar) ...

## Reto
...

## Autocorrección
1 ✅ · 2 🟡 · 3 ✅ · 4 ✅
Corrección 2: ...

## Lo que me costó / dudas
...
```

La sección "Lo que me costó" es la más útil para repasar antes del examen.

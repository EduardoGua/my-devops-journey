# Labs

Aquí cae lo que creas practicando **en tu Ubuntu** (bloque A y Git). Cada clase te dice qué carpeta crear: `labs/clase-03/`, etc.

Lo que haces en las VMs se queda en las VMs. Si algo de ahí merece guardarse (una configuración, un script), la clase te dice cómo traerlo.

Nunca subas aquí llaves privadas, contraseñas ni archivos `.env`: `.gitignore` bloquea los más comunes, pero la última revisión es tuya con `git status`.
